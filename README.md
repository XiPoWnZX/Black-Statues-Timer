# Black-Statues-Timer
Black Statues from Torn City

This is a private script for computer to always have the chain timer of Black Statues on your screen. There is a flashing timing for 1 minutes and sound for last 30 seconds.

You will need to create a custom private API key for use, it will be stored locally on your computer at AppData\Roaming\TornChainTimer\config.json
